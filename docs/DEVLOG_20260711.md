# 开发日志 2026-07-11

## 关闭窗口时持久化丢失

### 问题

删除任务后 5 秒内关闭应用，下次启动时被删除的任务重新出现。原因是 `PersistenceService` 使用 5 秒防抖延迟保存，窗口关闭时 `threading.Timer(daemon=True)` 被直接杀死，未保存的变更全部丢失。

### 修复

两处关闭入口各加一行 `persistence_service.save_if_dirty()`：

- `_close_window` — 自定义标题栏 X 按钮
- `_on_window_close` — 系统关闭回调

```python
persistence_service.save_if_dirty()  # 关闭前刷入未保存变更
```

### 踩坑

5s 防抖只影响 SQLite 持久化，不影响 UI 刷新（UI 走的是 50ms 异步防抖）。两个防抖机制相互独立，容易混淆排查方向。

## AI 修改 datetime 字段导致 Side Panel 崩溃

### 问题

AI 助手通过 `update_task` 修改 `planned_start` 后，点击该任务卡片打不开详情面板。同时自动保存也静默失败。

### 根因

LLM 调用工具时传的是字符串 `"2026-07-12 08:00"`，`write_tools.update_task()` 直接透传到 `state.update_task()` → `setattr(task, "planned_start", "字符串")`。Python dataclass 不做运行时类型校验，字符串直接写入。

后续两处崩溃：
- `side_panel._build()` → `t.planned_start.strftime(...)` → `AttributeError`（str 没有 strftime）
- `task.to_dict()` → `self.planned_start.isoformat()` → `AttributeError`（str 没有 isoformat）

### 修复

`write_tools.py:132-139` — 白名单过滤后，对 4 个 datetime 字段做类型转换：

```python
_DATETIME_FIELDS = {"due_date", "planned_start", "planned_end", "completed_at"}
for k in _DATETIME_FIELDS:
    if k in allowed_fields and isinstance(allowed_fields[k], str):
        allowed_fields[k] = datetime.fromisoformat(allowed_fields[k])
```

### 踩坑

Python dataclass 的类型标注只是标注，编译器/运行时都不校验。Agent 工具层必须在传入 state 之前做类型转换，不能依赖下游防御。

## Side Panel 不自动刷新

### 问题

AI 修改任务后，看板卡片自动刷新（50ms 防抖后），但如果该任务的详情面板已经打开，面板内容不会更新。用户需要手动关闭再打开才能看到最新数据。

`toggle_task()` 的逻辑：面板已打开且同一任务 → 关闭面板。用户看到的是"点了没反应"（其实面板被关掉了），再点一次才打开并显示新数据。

### 修复

两个改动：

1. **`side_panel.py:38-51`** — 新增 `refresh_if_open()` 方法：面板打开时从 state 重新拉取任务数据并重建内容。如果任务已被删除则自动关闭面板。
2. **`board_page.py:362-363`** — 每次 `_refresh_board()` 末尾调用 `self.side_panel.refresh_if_open()`

现在 AI 或任何后台操作修改任务后，已打开的详情面板会自动刷为最新数据。

## 新增 Agent 工具 search_tasks_by_title

### 背景

AI 助手已有 `search_related_tasks(ata_chapter)` 按 ATA 章节搜索任务，但没有按任务标题搜索的能力。用户提到具体任务名时 AI 无法定位。

### 实现

`board_tools.py` 新增 `search_tasks_by_title(query)` — 遍历所有任务，按标题和工单号模糊匹配（不区分大小写），返回最多 20 条结果（ID / 标题 / 状态 / ATA / 飞机 / 优先级）。

```python
@tool
def search_tasks_by_title(query: str) -> str:
    matched = [t for t in state.get_all_tasks()
               if q in t.title.lower()
               or q in t.work_order_id.lower()]
```
