## 本日踩坑

### Flet 0.28.3 新坑
| 坑 | 现象 | 解决 |
|----|------|------|
| `page.snack_bar` 不渲染 | setter 只存 Python 属性不发送 | 改 `page.overlay` 手动布局 |
| `read_only=True` TextField 不显示 value | 文本不可见 | 锁定态用纯 `ft.Text` |
| `Container.mouse_cursor` 不支持 | TypeError | 移除 |
| `page.overlay` 中 `expand=True` 无效 | 容器不填满 | 显式设 `width/height` |
| 控件未挂载时 `.update()` 崩溃 | AssertionError | 移除挂载前 update |
| 两个 `expand=True` 在同一 Row | 布局异常 | 各占独立行 |

### 线程/异步坑
| 坑 | 现象 | 解决 |
|----|------|------|
| `threading.Thread` 定义但未 `.start()` | 工具卡死不响应 | 2 处遗漏修复 |
| `cancel_event` 跨线程查 `self.ai_chat._cancel_event` | 偶发 None | 调用方传入局部变量 |
| `_rebuild_bubbles` 从非 msg_pairs 追加的数据 | 重建时丢失 | 提案结果/状态气泡独立存储 |

### 路径坑
| 坑 | 现象 | 解决 |
|----|------|------|
| `persistence_service.set_path` 用 `../../..`×2 | 落到 `app/data/` | 改 `../../..`×3 |
| `ModalDialog` 缺少 `height` 参数 | 弹窗不居中 | 新增参数 |

### AI 提示词坑
| 坑 | 现象 | 解决 |
|----|------|------|
| Agent 绕过"先提问"直接创建任务 | 监控失效 | 提取到 .md + strict=True + ❌写工具 |
| 大纲工具误创建任务 | 提示词无禁止 | generate_outline.md 加 FORBIDDEN 规则 |
